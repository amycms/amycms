### 🧠 CDR-Net — 시계열 신경교종 병변 변화 예측 연구  
> `2025.09 ~ 2026.05`

치료 후 신경교종 환자의 시계열 MRI 데이터를 활용해 미래 병변 변화를 예측하는 의료 AI 연구입니다.  
단일 시점의 multi-modal MRI 입력만으로 Edema와 Active Tumor의 증가/감소 변화를 voxel-wise로 예측하고, 이를 기반으로 후속 시점의 병변 마스크를 재구성하는 프레임워크를 설계했습니다.

- **연구 주제**: 신경교종 환자의 시계열 병변 변화 예측
- **핵심 아이디어**: ED/AT 병변 변화를 INC/DEC로 분해하고, dual-decoder 구조로 병변별 변화 패턴 학습
- **연구 방법**: U-Net 기반 Shared Residual Encoder와 Dual Decoder 구조 설계
- **주요 기여**: 병변 변화 예측과 후속 시점 재구성을 함께 수행하는 딥러닝 파이프라인 설계 및 논문 작성
- **기술 스택**: `PyTorch` `NumPy` `Medical Image Analysis` `Deep Learning`

### 🧬 PG_GraphSSL — 표현형-유전형 관계 모델링 기반 그래프 자가지도학습 연구  
> `2025.06 ~ 2025.10`

MRI, SNP, 인구통계 정보를 활용해 퇴행성 뇌질환인 알츠하이머의 고차원 패턴을 학습하는 그래프 기반 자가지도학습 연구입니다.  
표현형과 유전형 간 관계를 그래프로 모델링하고, 질환 분류와 인지 점수 예측을 함께 수행하는 프레임워크를 설계했습니다.

- **연구 주제**: A Novel Self-Supervised Deep Learning Framework for Pattern Recognition of Neurodegenerative Disease via Graph-based Phenotype–Genotype Relation Modeling
- **핵심 아이디어**: phenotype-genotype 관계 모델링, graph neural network, self-supervised pretext task 설계
- **연구 결과**: SAC 2026 논문 채택 및 발표, 확장본 MedIA 저널 제출
- **기술 스택**: `Python` `PyTorch` `Graph Neural Network` `Self-Supervised Learning`

### 🧪 AD_SSL — 퇴행성 뇌질환 조기 진단 자가지도학습 연구  
> `2025.03 ~ 2025.06` | [🔗Paper](https://drive.google.com/file/d/1xLmii0rHMxKl9XijAUx8BxWK54Muccz1/view?usp=drive_link) | [🔗GitHub](https://github.com/amycms/AD_SSL)

자가지도학습을 활용해 퇴행성 뇌질환 조기 진단 프레임워크의 성능을 개선한 연구 프로젝트입니다.  
SimCLR 기반 feature extractor를 설계하고, 추출된 representation을 SVC, Random Forest, Gaussian Process Classifier 등 전통적 머신러닝 모델에 적용해 진단 성능을 비교했습니다.

- **연구 주제**: Improving Machine Learning-based Early Diagnosis Framework of Degenerative Brain Disease through Self-Supervised Learning
- **핵심 아이디어**: SimCLR 기반 feature representation 학습
- **적용 모델**: SVC, Random Forest, Gaussian Process Classifier
- **연구 결과**: KCC 2025 논문 게재 및 포스터 발표
- **활용 데이터**: ADNI MRI, SNP, demographic data
- **기술 스택**: `Python` `PyTorch` `Scikit-learn` `Pandas` `NumPy`
